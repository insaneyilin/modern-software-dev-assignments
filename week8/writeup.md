## App Concept

A simplified note-taking application inspired by Simplenote. The app features a clean, two-panel interface with a searchable note list on the left sidebar and an editor panel on the right. Users can create, read, update, and delete notes with real-time auto-save functionality. The application includes full-text search across note titles and content, with notes sorted by most recently updated. All data is persisted to a database with a functional UI that surfaces the main CRUD flows.
